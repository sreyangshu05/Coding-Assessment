# 🧮 Python Assessment Solutions

This repository contains solutions to a Python programming assessment.

---

## 🚀 Overview

The solutions demonstrate the use of core Python concepts such as:
- Object-Oriented Programming (OOP)
- Loops and conditional logic
- User input handling
- Dictionary operations

All programs are **user-input driven** and written with clarity and simplicity

---

## 📂 Problems Covered

- **Calculator using Classes**  
  Performs Addition, Subtraction, Multiplication, and Division.

- **Odd Number Series Generation**  
  Generates a series of odd numbers based on the input value.

- **Conditional Series Generation**  
  Outputs odd-number series depending on whether the input is odd or even.

- **Counting Multiples Using Dictionary**  
  Counts how many numbers in a list are multiples of numbers from 1 to 9.
